# Universidad de Chile WebCal 🔵🔴🏆

Calendario automático de Universidad de Chile compatible con:

- Apple Calendar
- Google Calendar
- Outlook

🌐 Sitio web:

https://jebusrf.github.io/UdeChileWebCal/

## Tecnologías

- Python
- GitHub Actions
- GitHub Pages
- ESPN Core API
- iCalendar (.ics)

## Funciones

- Actualización automática de fixtures
- Primera División
- Copa Chile
- Preparado para Libertadores, Sudamericana, Supercopa y amistosos
- Compatibilidad multiplataforma

## Proyecto

Universidad de Chile WebCal es un proyecto independiente.

No afiliado oficialmente a Universidad de Chile, ANFP ni ESPN.
