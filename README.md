# Colo-Colo WebCal ⚪⚫🏆

Calendario automático de Colo-Colo compatible con:

- Apple Calendar
- Google Calendar
- Outlook

🌐 Sitio web:

https://jebusrf.github.io/Colo-ColoWebCal/

## Tecnologías

- Python
- GitHub Actions
- GitHub Pages
- ESPN Core API
- iCalendar (.ics)

## Funciones

- Actualización automática de fixtures
- Primera División
- Copa Chile
- Preparado para Libertadores, Sudamericana, Supercopa y amistosos
- Compatibilidad multiplataforma

## Proyecto

Colo-Colo WebCal es un proyecto independiente.

No afiliado oficialmente a Colo-Colo, ANFP ni ESPN.
